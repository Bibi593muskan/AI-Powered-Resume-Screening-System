# AI-Powered-Resume-Screening-System
AI-Powered Resume Screening System uses NLP and machine learning to automatically scan and evaluate resumes. It extracts key details like skills and experience, compares them with job requirements, and ranks candidates, helping recruiters shortlist efficiently and accurately.

## Project Overview
Manual resume screening is time-consuming and inefficient. This system automates the process by extracting key skills and information from resumes and comparing them with job descriptions, helping recruiters shortlist candidates faster and more accurately.

## Features
- Resume parsing using NLP techniques
- Skill and keyword matching with job requirements
- Automatic candidate ranking
- Simple and user-friendly web interface
- Reduces manual effort in recruitment

## Technologies Used
- Python
- NLP libraries
- Flask (backend)
- HTML & CSS (frontend)
- VS Code

## How to Run
1. Install Python on your system
2. Install required libraries using `pip install flask`
3. Open the project folder in VS Code
4. Run the main Python file
5. Access the web interface through the local browser

## Applications
- Recruitment and HR automation
- Resume shortlisting systems
- Talent acquisition platforms
